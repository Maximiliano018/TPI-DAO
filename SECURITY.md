# Política de seguridad

Si encontrás una vulnerabilidad, **no abras un issue público**. Usá *Security > Report a vulnerability* de este repositorio o escribí a los mantenedores.

Buenas prácticas del proyecto:
- Sin credenciales ni datos reales en el repositorio; usar variables de entorno y `.env` (ignorado por git).
- Contraseñas siempre hasheadas, nunca en texto plano.
- Mantener dependencias actualizadas (Dependabot).
